# Рабочий стол PHN16-71

Локальная история настроек Hyprland, изменений Serpantinum и исправления профилей Acer.
Версии исходников записаны в `upstream.json`. Репозиторий не имеет удалённого сервера.

## Что сохранено

- `home/` — настройки Hyprland, порталов и изменённые файлы оболочки.
- `system/` — исходник драйвера Acer, его служба, правило доступа к пяти профилям и PAM-профиль.
- `serpantinum.patch` — наши изменения относительно исходной Serpantinum 2.2.12.
- `upstream/` — оригиналы затронутых файлов для повторного создания патча.
- `settings.json` — оформление и выбранные настройки без геолокации и временного состояния.
- `packages.txt` — основные системные зависимости; для сборки драйвера нужны заголовки текущего ядра.

Автоблокировка выключена по выбору владельца (`idle.enabled=false`).
Индикатор профиля в верхнюю панель не добавлен.

## После обновления Serpantinum

    python ~/desktop-config/restore.py
    ~/.local/bin/serpantinum reload

Сначала патч проверяется в отдельной временной папке. При конфликте новой версии
файлы рабочего стола не меняются. Перед применением создаётся резервная копия
в `~/.local/state/desktop-config/`.

Настройки оболочки сохраняются текущими. Чтобы также вернуть сохранённое оформление
и параметры бездействия:

    python ~/desktop-config/restore.py --settings

Оригинальные ресурсы Serpantinum — шрифты, изображения, звуки — должны быть установлены.
Снимок не заменяет установку самой оболочки.

## Сохранить следующие изменения

    python ~/desktop-config/capture.py
    python ~/desktop-config/make-overlay.py
    git -C ~/desktop-config add .
    git -C ~/desktop-config commit -m "Описание изменения"

Исходная конфигурация до этих улучшений сохранена в первом коммите. Для просмотра истории:

    git -C ~/desktop-config log --oneline
    git -C ~/desktop-config diff

Для возврата к нужной версии сначала создай отдельную ветку от нужного коммита,
затем примени её через `restore.py`. Текущие файлы будут сохранены в резервной копии.

## Восстановить системную часть Acer

Обычно служба `turbo-fan` сама пересобирает исправленный исходник при смене ядра.
Для ручного восстановления на этой же модели:

    bash ~/desktop-config/build-driver.sh
    sudo bash ~/desktop-config/install-system.sh

Установщик проверяет совпадение версии ядра и модуля, сохраняет копии системных файлов
в `/var/backups/desktop-config/`, устанавливает новый модуль для следующей загрузки.
После этого следует перезагрузить компьютер.

## Датчики

В системной панели (`Super+B`) показаны температуры CPU/GPU и обороты двух вентиляторов.
CPU и Acer считываются через hwmon. Температура NVIDIA запрашивается только при открытой
панели и работающей видеокарте; спящая видеокарта не пробуждается для обновления датчика.
Период обновления — три секунды. Недоступное показание отображается как «—».

## Демонстрация экрана

Установлен `xdg-desktop-portal-hyprland`, для ScreenCast/Screenshot/GlobalShortcuts
явно выбран backend Hyprland. Окружение Wayland передаётся службам при запуске сеанса.
Службы портала работают и экспортируют интерфейсы захвата экрана.
Выбор источника и передача видео в конкретном браузере/приложении отдельно не проверялись.
